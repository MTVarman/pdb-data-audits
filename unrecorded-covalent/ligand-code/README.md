# Bonds inside the processing distance window that the Protein Data Bank still leaves unrecorded, and how much of them the ligand code's history predicts

Michael T. Varman · [ORCID 0009-0001-9453-0226](https://orcid.org/0009-0001-9453-0226)

The scripts recount the note, redraw its figures, and test whether a ligand code's earlier bond record predicts later protein–ligand contacts that the processing distance window still leaves unrecorded. `scripts/ligand_code_effect/` is that carry-forward analysis, `scripts/mpro_covalent_census/` is the SARS-CoV-2 Mpro census, and `scripts/note/verify_numbers.py` checks the numbers quoted in the note.

Note (all versions): [10.5281/zenodo.24285353](https://doi.org/10.5281/zenodo.24285353).

Scripts and tables at or under 1 MiB are copied byte-for-byte from `Varman_covale_ligand_code_addendum_v1.1_bundle.zip` on Zenodo record 24333959, the latest version of the note. Larger tables stay in the zip.
